# 08 — مراحل التنفيذ (Roadmap)

المدد تقديرية لفريق صغير (2 Backend، 2 Flutter، 1 Frontend، 1 QA، 1 Designer، مدير منتج). كل مرحلة تنتهي بشيء يعمل ويمكن اختباره.

| المرحلة | المدة | النتيجة |
|---|---|---|
| 0. التصميم والتأسيس | 3 أسابيع | ✅ هذا المستودع: المعمارية، قاعدة البيانات، التدفقات، الشاشات، الصلاحيات، منطق التسعير والتوزيع |
| 1. البنية الأساسية | 3 أسابيع | Backend يعمل + مصادقة + أدوار |
| 2. السائق والموافقة | 3 أسابيع | تسجيل السائق ومراجعته من اللوحة |
| 3. الخرائط والتسعير | 3 أسابيع | العميل يرى السعر التقديري الصحيح |
| 4. الرحلة الكاملة (MVP) | 5 أسابيع | رحلة نقدية كاملة من الطلب حتى التقييم |
| 5. المال | 4 أسابيع | المحافظ، العمولة، ديون النقد، بوابات الدفع المحلية |
| 6. الإدارة والتقارير | 3 أسابيع | لوحة كاملة + تقارير + تصدير |
| 7. الأمان والدعم والعروض | 3 أسابيع | SOS، التذاكر، الكوبونات، الإحالة |
| 8. الإطلاق التجريبي | 4 أسابيع | Pilot في أربيل |
| 9. التوسع | مستمر | مدن جديدة، تحسينات، خدمات جديدة |

**MVP قابل للإطلاق التجريبي ≈ 6 أشهر.**

## المرحلة 1 — البنية الأساسية
- Monorepo: `apps/api` (NestJS)، `apps/admin` (Next.js)، `apps/passenger` و `apps/driver` (Flutter)، `packages/core`, `packages/i18n`
- Docker Compose: PostgreSQL+PostGIS, Redis, MinIO
- CI: lint + typecheck + tests + build لكل تطبيق
- Auth: OTP (SMS + WhatsApp)، JWT + Refresh، أجهزة، Rate limiting
- Admin auth + 2FA + RBAC + Audit Log
- ملف الترجمة الموحد (ar / en / ckb) + RTL
- Seed: العراق، المدن الخمس، أنواع السيارات، الأدوار والصلاحيات

## المرحلة 2 — السائق والموافقة
- تسجيل السائق ورفع المستندات (روابط رفع موقّعة، ضغط الصور، كاميرا بإطار)
- تشفير رقم الهوية والرخصة
- لوحة: طابور الموافقة، مراجعة المستندات، كل حالات السائق، سجل الحالات
- إشعارات تغيير الحالة
- مهمة يومية: تنبيه قبل انتهاء المستندات بـ 30/7/1 يوم، وتحويل الحالة إلى `DOCUMENTS_EXPIRED`

## المرحلة 3 — الخرائط والتسعير
- واجهة `MapProvider` + تطبيق Google Maps (+ Mapbox كبديل)
- البحث عن الأماكن بالعربية والكردية والإنجليزية + الأماكن المحفوظة
- المدن والمناطق (رسم Polygon في اللوحة)
- قواعد التسعير + محاكي السعر في اللوحة
- خدمة الذروة (كل 60 ثانية) + الجداول + Override
- API عرض السعر (Quote) لكل أنواع السيارات

## المرحلة 4 — الرحلة الكاملة (MVP)
- Redis GEO + WebSocket لمواقع السائقين
- Online/Offline + شروط الاتصال
- محرك التوزيع (Matching) مع BullMQ للمهلات
- آلة حالات الرحلة كاملة + PIN البدء + التحقق من مسافة "وصلت"
- التتبع الحي + ETA + الملاحة (داخلية + فتح Google Maps/Waze)
- الدردشة داخل الرحلة + ردود سريعة + الاتصال
- السعر النهائي من GPS + الدفع النقدي
- التقييم المتبادل
- الإلغاء مع الأسباب والرسوم
- Push (FCM + HMS + APNs) لكل أحداث الرحلة
- **معيار الخروج**: 200 رحلة تجريبية داخلية بدون أخطاء حرجة

## المرحلة 5 — المال
- دفتر القيود (Ledger) للمحافظ
- العمولات بكل مستوياتها + التسوية لكل رحلة
- ديون العمولة النقدية + الحد + التسديد
- بوابة دفع محلية أولى (ZainCash أو FIB) للشحن والدفع
- بطاقات (Qi Card / Visa / Mastercard عبر مزوّد محلي) مع Tokenization
- سحوبات السائقين + اعتماد مالي
- استرجاع المبالغ + Maker-Checker
- مطابقة يومية (Reconciliation) مع كشوف البوابات

## المرحلة 6 — الإدارة والتقارير
- لوحة اليوم المباشرة + الخريطة الحية
- إدارة السائقين والعملاء والرحلات كاملة (بحث، فلترة، ترتيب، تصدير)
- التقارير كلها + تحليل ساعات ومناطق الذروة + العرض مقابل الطلب
- تصدير Excel و PDF (يدعم العربية RTL)

## المرحلة 7 — الأمان والدعم والعروض
- SOS: إشعار فوري للوحة + جهات الطوارئ + تسجيل الموقع
- مشاركة الرحلة برابط عام مؤقت
- التذاكر بكل الفئات + الإسناد + الردود
- الكوبونات، الإحالة، حوافز السائقين
- كشف الاحتيال الأساسي (GPS وهمي، حسابات متعددة، إساءة الكوبونات)

## المرحلة 8 — الإطلاق التجريبي (Pilot)
- اختبار الحمل: 5,000 سائق متصل يرسل موقعه كل 4 ثوانٍ
- اختبار اختراق (Pentest) خارجي
- نشر على Google Play + App Store + AppGallery (Huawei)
- تجنيد وتدريب 150–300 سائق في أربيل قبل فتح التطبيق للعملاء
- مكتب استقبال سائقين لفحص السيارات ومطابقة المستندات وجهًا لوجه
- إطلاق تدريجي: موظفون ← دعوات ← عام
- مراقبة يومية لمؤشرات: وقت الوصول، نسبة الطلبات بدون سائق، الإلغاء، التقييم

## المرحلة 9 — التوسع
- مدن: دهوك ← السليمانية ← بغداد ← البصرة (لكل مدينة: تسعير، مناطق، مطار، تجنيد سائقين، مكتب)
- اللهجة البادينية (kmr) لدهوك
- Batch matching، رحلات متتالية، توجيه السائقين للطلب
- فصل `tracking` و `matching` كخدمات مستقلة عند الحاجة
- خدمات جديدة على نفس البنية: توصيل طرود، مطار، شركات، دراجات…
- دول جديدة: إضافة صف في `countries` + بوابة دفع + مزوّد SMS + ترجمة
