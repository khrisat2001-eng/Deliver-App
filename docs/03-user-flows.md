# 03 — رحلة المستخدم الكاملة (Complete User Flow)

## 1. العميل (Passenger)

### 1.1 التسجيل والدخول
```
فتح التطبيق → اختيار اللغة (عربي / English / کوردی) → إدخال رقم الهاتف (+964)
→ استلام OTP (SMS، ثم WhatsApp أو مكالمة صوتية كبديل) → إدخال الرمز
  ├─ رقم جديد → الاسم الكامل + (بريد، صورة، تاريخ ميلاد، جنس — اختياري) + كود إحالة اختياري → قبول الشروط
  └─ رقم موجود → الدخول مباشرة
→ طلب صلاحية الموقع والإشعارات → الشاشة الرئيسية (الخريطة)
```
- بديل: بريد + كلمة مرور (لمن أضاف بريدًا). نسيت كلمة المرور ← رابط/رمز على البريد.
- تغيير رقم الهاتف: OTP على الرقم القديم (إن أمكن) + OTP على الرقم الجديد، ثم تسجيل خروج كل الأجهزة الأخرى.
- الحساب غير الموثّق (بدون OTP) لا يستطيع طلب رحلة.

### 1.2 طلب رحلة
```
الشاشة الرئيسية: الخريطة على الموقع الحالي + "إلى أين؟"
→ اختيار الوجهة (بحث / المنزل / العمل / الأماكن الأخيرة / تحريك الدبوس)
→ تأكيد نقطة الانطلاق (تحريك الدبوس + حقل "علامة دالة" مثل: قرب جامع ...)
→ شاشة اختيار السيارة: لكل نوع (السعر التقديري، وقت الوصول، عدد المقاعد) + شارة الذروة إن وجدت
→ اختيار طريقة الدفع (نقدًا افتراضيًا / محفظة / ZainCash / FIB / بطاقة) + كود خصم
→ "اطلب الآن" → شاشة البحث عن سائق (يمكن الإلغاء مجانًا)
  ├─ قبل سائق → شاشة السائق في الطريق
  └─ لا يوجد سائق (بعد كل الجولات) → رسالة + "حاول مرة أخرى" / تغيير نوع السيارة
```
السعر التقديري صالح لمدة محددة (مثلًا 5 دقائق). إذا انتهت أو تغيّر معامل الذروة يُعاد التسعير قبل التأكيد.

### 1.3 أثناء الرحلة
```
السائق في الطريق: (الاسم، الصورة، التقييم، السيارة، اللون، اللوحة، ETA، الموقع الحي)
  أزرار: اتصال (رقم مخفي) / دردشة / مشاركة الرحلة / إلغاء / SOS
→ وصل السائق: إشعار + عدّاد الانتظار المجاني + رمز PIN لبدء الرحلة
→ بدأت الرحلة: تتبع حي حتى الوجهة، ETA للوصول، زر SOS ومشاركة الرحلة دائمًا ظاهر
→ انتهت الرحلة: ملخص السعر النهائي (تفصيل) → الدفع
→ تقييم السائق (1–5 + وسوم + تعليق + بقشيش اختياري لاحقًا) → الرئيسية
```

### 1.4 بعد الرحلة
- سجل الرحلات مع إيصال وخريطة المسار.
- "أبلغ عن مشكلة" من الرحلة ← تذكرة دعم مرتبطة بالرحلة (أغراض مفقودة، سعر خاطئ، سلوك السائق…).
- المحفظة: الرصيد، شحن، السجل، الاسترجاعات، الرصيد الترويجي.
- الإحالة: مشاركة الكود عبر WhatsApp/Telegram/SMS.

## 2. السائق (Driver)

### 2.1 التسجيل والموافقة
```
فتح التطبيق → اللغة → الهاتف + OTP
→ البيانات الشخصية (الاسم، الصورة، البريد، المدينة)
→ الهوية (البطاقة الوطنية الموحدة: وجه + ظهر، الرقم)
→ رخصة القيادة (صورة + رقم + تاريخ الانتهاء)
→ السيارة (النوع، الشركة، الموديل، السنة، اللون، رقم اللوحة + المحافظة، صور 4 جهات + الداخل)
→ سنوية السيارة (التسجيل) + التأمين + (عدم محكومية إن تطلبت المدينة)
→ مراجعة وإرسال → الحالة: PENDING
→ شاشة "حسابك قيد المراجعة" مع حالة كل مستند
  ├─ CHANGES_REQUESTED → إشعار بالمستند المطلوب تعديله → إعادة الرفع → UNDER_REVIEW
  ├─ REJECTED → إشعار بالسبب
  └─ APPROVED → إشعار + جلسة تعريفية قصيرة (فيديو/أسئلة) → يمكن الاتصال Online
```

### 2.2 يوم عمل السائق
```
الرئيسية: زر "اتصال" (Online/Offline) + الأرباح اليوم + خريطة الذروة (Heatmap)
  شرط الاتصال: الحساب APPROVED + المستندات سارية + ديون العمولة النقدية أقل من الحد
→ وصول عرض رحلة: (المسافة للعميل، ETA، منطقة الوجهة، السعر التقديري، طريقة الدفع) + عدّاد 15 ثانية
  ├─ رفض / انتهاء الوقت → يُسجّل، العرض يذهب لسائق آخر
  └─ قبول → ملاحة إلى العميل (داخلية أو فتح Google Maps / Waze)
→ "وصلت" (مسموح فقط ضمن 150م من نقطة الانطلاق) → عدّاد الانتظار
→ إدخال PIN من العميل → "بدء الرحلة" → ملاحة إلى الوجهة
→ "إنهاء الرحلة" → السعر النهائي → إذا نقدًا: "استلمت المبلغ" → تقييم العميل
→ يعود ONLINE تلقائيًا
```

### 2.3 المال
- المحفظة: الأرباح، العمولة، المكافآت، دين العمولة النقدية، السحب.
- طلب سحب إلى ZainCash / FIB / FastPay / حساب بنكي / استلام من المكتب.
- تسديد دين العمولة عبر المحفظة الإلكترونية أو في نقطة تحصيل.

## 3. الإدارة (Admin)

```
تسجيل الدخول (بريد + كلمة مرور + 2FA) → لوحة اليوم + الخريطة الحية
├─ السائقون الجدد → فتح الطلب → مراجعة كل مستند (قبول/رفض بسبب) → موافقة / طلب تعديل / رفض
├─ الرحلات النشطة → فتح رحلة → تتبع حي → تدخل (إلغاء، إعادة إسناد، التواصل)
├─ تنبيه SOS → إشعار فوري صوتي في اللوحة → فتح الحادثة → الاتصال بالطرفين → تصعيد → إغلاق
├─ التسعير → اختيار مدينة/منطقة/نوع سيارة → تعديل → معاينة سعر رحلة تجريبية → حفظ (يُسجّل في Audit)
├─ التذاكر → إسناد → رد → تغيير الحالة → إغلاق
└─ التقارير → فلترة → تصدير Excel / PDF
```
