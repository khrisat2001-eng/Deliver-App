# Ride Booking & Taxi Application

منصة نقل وطلب سيارات أجرة (مثل Uber و Careem من حيث الوظائف) موجهة للعراق وإقليم كوردستان.

هذه النسخة **موقع ثابت (HTML + CSS + JavaScript فقط) بدون خادم**، وتعمل على GitHub Pages:

| الصفحة | الملف | المحتوى |
|---|---|---|
| الصفحة الرئيسية | `index.html` | روابط التطبيقات الثلاثة وطريقة التجربة |
| تطبيق الراكب | `passenger.html` | تسجيل بالهاتف + OTP أو بالبريد وكلمة المرور (مع نسيت كلمة المرور)، الخريطة، اختيار الوجهة، السعر المسبق لكل نوع سيارة، الذروة، الكوبونات، طرق الدفع (نقد، محفظة، ZainCash، FIB، FastPay، بطاقة)، التتبع المباشر، رمز PIN لبدء الرحلة، الدردشة، مشاركة الرحلة، SOS، الإلغاء مع الرسوم، التقييم، سجل الرحلات، المحفظة، الإحالة، الأماكن المحفوظة، جهات الطوارئ، الدعم |
| تطبيق السائق | `driver.html` | التسجيل مع رفع المستندات وتواريخ الانتهاء، حالة الموافقة، الاتصال/قطع الاتصال، عروض الرحلات مع عدّاد، الملاحة (Google Maps)، وصلت ← PIN ← بدء ← إنهاء، تحصيل النقد، تقييم الراكب، الأرباح، دين العمولة النقدية والتسديد، طلب السحب، المستندات، القيادة المحاكاة أو GPS حقيقي |
| لوحة الإدارة | `admin.html` | المؤشرات المباشرة والخريطة الحية، الموافقة على السائقين ومراجعة المستندات، السائقون، العملاء، الرحلات (مع المسار وسجل التوزيع)، حوادث SOS، التذاكر، المدن والمناطق، أنواع السيارات، الأسعار + محاكي السعر، الذروة (ديناميكي + مجدول + يدوي)، العمولات، سياسة الإلغاء، العروض، المدفوعات ودفتر القيود، السحوبات وديون النقد، التقارير وتحليل ساعات الذروة مع تصدير Excel/PDF، الإشعارات الجماعية، الأدوار والصلاحيات، سجل التدقيق، الإعدادات |

**تطبيقا الراكب والسائق قابلان للتثبيت (PWA)** على Android و iOS من المتصفح: يظهر زر "تثبيت التطبيق" في صفحة الحساب (وعلى الآيفون: مشاركة ← إضافة إلى الشاشة الرئيسية)، ويفتحان بدون إنترنت للصفحات التي فُتحت سابقًا (`sw.js`).

اللغات: **العربية والكوردية (سوراني) بالاتجاه من اليمين لليسار، والإنجليزية من اليسار لليمين**، وكل النصوص في ملفات `assets/locales/{ar,ckb,en}.json`.

## كيف يعمل بدون خادم

- **قاعدة البيانات** هي `localStorage` في المتصفح (`assets/js/lib/db.js`)، جدول لكل مفتاح، مع بيانات تجريبية للعراق: 5 مدن، مناطق ومطارات، 6 أنواع سيارات، أسعار، حوالي 40 سائقًا محاكى، 40 عميلًا، و30 يومًا من الرحلات السابقة للتقارير.
- **التبويبات تتزامن** عبر حدث `storage`: افتح الراكب في تبويب والسائق في تبويب آخر وسيتواصلان مباشرة.
- **"الخادم"** (`assets/js/lib/engine.js`) يعمل في تبويب واحد فقط يتم اختياره تلقائيًا (leader election): توزيع الرحلات، مهلات العروض، حركة السيارات المحاكاة، حساب الذروة، انتهاء المستندات.
- **منطق الأعمال** (التسعير، الذروة، العمولة، التوزيع، حالات الرحلة، الإلغاء، الكوبونات) مكتوب بـ TypeScript في `packages/core` مع 42 اختبارًا، ومترجم إلى JavaScript في `assets/js/core`.
- **الخرائط**: Leaflet (مضمّن في `assets/vendor`) مع خرائط OpenStreetMap. المسارات من OSRM والبحث من Nominatim عند توفر الإنترنت، وإلا يُستخدم تقدير بالخط المستقيم والمعالم المحلية.

### الحدود (مهم)

- البيانات موجودة **في هذا المتصفح فقط**. هاتف آخر لن يرى رحلاتك. للتجربة بين راكب وسائق افتح تبويبين في نفس المتصفح.
- لا توجد رسائل SMS أو مدفوعات أو إشعارات Push حقيقية؛ كلها محاكاة وتظهر على الشاشة.
- أي شخص يستطيع تعديل `localStorage`، لذلك هذه النسخة **عرض تجريبي وليست آمنة للإنتاج**. للإطلاق الحقيقي ينتقل نفس المنطق إلى خادم حسب وثائق التصميم في `docs/`.

## التجربة محليًا

ملفات JavaScript هي ES modules، لذلك تحتاج خادمًا بسيطًا (لا تعمل بفتح الملف مباشرة):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

الحسابات التجريبية: الراكب `0750 000 0000`، السائق `0750 111 1111` (رمز التحقق يظهر على الشاشة). الإدارة: اختر أي دور في شاشة الدخول.

## النشر على GitHub Pages

GitHub Pages مفعّل على هذا المستودع وينشر الموقع مباشرة من جذر الفرع الافتراضي (**Settings → Pages → Deploy from a branch**). أي push إلى الفرع يحدّث الموقع خلال دقيقة أو اثنتين. يوجد ملف `.nojekyll` حتى تُنشر الملفات كما هي.

الملف `.github/workflows/main.yml` يشغّل الاختبارات وفحص الترجمات عند كل push.

```
index.html, passenger.html, driver.html, admin.html   صفحات الموقع
assets/css/app.css                                    التصميم (فاتح/داكن، RTL/LTR، متجاوب)
assets/locales/                                       الترجمات ar / ckb / en
assets/js/passenger.js, driver.js, admin.js           التطبيقات الثلاثة
assets/js/lib/                                        قاعدة البيانات، المحرك، الخرائط، الواجهة، الترجمة، البيانات التجريبية
assets/js/core/                                       منطق الأعمال المترجم من packages/core (لا تعدّله يدويًا)
assets/vendor/leaflet/                                مكتبة الخرائط
packages/core/                                        منطق الأعمال بـ TypeScript + الاختبارات
scripts/check-i18n.mjs                                فحص الترجمات
apps/api/prisma/schema.prisma                         قاعدة بيانات الخادم المستقبلي
docs/                                                 وثائق التصميم (المعمارية، قاعدة البيانات، التدفقات، الشاشات، الصلاحيات، التسعير، التوزيع، المراحل، التشغيل والدفع المحلي)
```

## الأوامر

```bash
cd packages/core && npm install
npm test               # 42 اختبارًا
npm run typecheck
npm run build:site     # يعيد بناء assets/js/core بعد أي تعديل على منطق الأعمال
node ../../scripts/check-i18n.mjs

# اختبار شامل في متصفح حقيقي (من جذر المستودع)
npm i -D playwright && npx playwright install chromium   # مرة واحدة
node tests/e2e.mjs
```

الاختبار الشامل يفتح التطبيقات الثلاثة في متصفح واحد ويجرّب: رحلة كاملة مع سائق حقيقي (مع كوبون والتحقق من حساب العمولة)، رحلة مع سائق محاكى مدفوعة بالمحفظة، الدخول بالبريد ونسيت كلمة المرور، التثبيت (PWA)، كل صفحات الإدارة، الموافقة على سائق، الصلاحيات، واللغات الثلاث.
